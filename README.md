# dbLinter CLI

## Introduction

This is the [Homebrew](https://brew.sh/) repository containing the formulae to install the [dbLinter](https://grisselbav.github.io/dbLinter/) command-line tool.

## Installation

```bash
brew install grisselbav/dblinter/dblinter
```

This is equivalent to running `brew tap grisselbav/dblinter` followed by `brew install dblinter`.

## Update

```bash
brew update && brew upgrade dblinter
```
